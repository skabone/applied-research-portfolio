# Data

This folder contains the public Kaggle Titanic competition files used by the analysis:

- `train.csv`: 891 labeled passenger records with the `Survived` outcome.
- `test.csv`: 418 unlabeled passenger records for competition submission.

Source: Kaggle. (2012). *Titanic: Machine Learning from Disaster*. https://www.kaggle.com/c/titanic

The data are a public benchmark dataset. No private client, employer, or personal records are included.
