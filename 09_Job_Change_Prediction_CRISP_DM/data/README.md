# Data Source

This folder contains the public Kaggle dataset used for Project 09:

- `aug_train.csv`
- `aug_test.csv`

Source: Kaggle, **HR Analytics: Job Change of Data Scientists**  
URL: https://www.kaggle.com/datasets/arashnic/hr-analytics-job-change-of-data-scientists

The dataset is listed on Kaggle with a **CC0: Public Domain** license. It is included here so the analysis can be rerun from the repository without relying on local source folders or cloud-drive paths.
