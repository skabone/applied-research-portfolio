# Wiki Source Map

The repository README remains the main entry point because it appears directly on the repository homepage and stays versioned with the project files. A Wiki can mirror the source files below without replacing the README.

## Recommended Wiki Pages

| Wiki page | Source file to mirror |
|---|---|
| Index | `README.md` plus `docs/index.md` |
| Project Catalog | `docs/project-catalog.md` |
| Methods Map | `docs/methods-map.md` |
| Reading Guide | `docs/reading-guide.md` |
| Portfolio Changelog | `CHANGELOG.md` |

## Maintenance Rule

When a project is rebuilt or a new figure layer is added, update the project README first, then update `docs/project-catalog.md`, `docs/methods-map.md`, and `CHANGELOG.md` if the change affects repository-level navigation.
