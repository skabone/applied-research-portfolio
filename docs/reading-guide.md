## Notes On Depth

Each polished project separates quick orientation from technical inspection. The README gives the problem and main result, `01_Project_Summary.md` gives a concise findings-first narrative, `02_Project_Report.md` gives the full methods and interpretation, and `03_*` or `04_*` files preserve workflow details.
