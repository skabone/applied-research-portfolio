# Data

This folder contains the project-local copy of the public ISLR College dataset used by Project 07.

| File | Description |
|---|---|
| `College_Data.csv` | Public teaching dataset with `777` U.S. colleges and universities and institutional profile variables such as applications, enrollment, tuition, instructional expenditure, faculty credentials, student-faculty ratio, alumni giving, graduation rate, and private/public status. |

The dataset is included here so `04_Source_Code.py` and `03_Analysis_Notebook.ipynb` can run from the repository without depending on private course folders or local cloud-drive paths.

This is an educational public dataset, not current operational data from a college, employer, or client.
